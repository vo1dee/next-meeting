# Marketplace assets

Drop final Marketplace submission assets into the matching folder.

| Folder | Contents |
| --- | --- |
| `icon/` | Final plugin icon: `next-meeting-icon-512.png` (512 × 512 PNG). Keep any editable SVG/source files here too. |
| `screenshots/` | Five to eight numbered PNGs captured from the final plugin build, such as `01-countdown-key.png` through `08-privacy.png`. Redact real meeting data, email addresses, and join URLs. |
| `promo-banners/` | Final banner exports and editable source. Name files by their Marketplace-required dimensions, for example `promo-banner-1920x1080.png`. |
| `listing-copy/` | Final short description, long description, feature list, and keywords. |

Confirm the Marketplace's current image dimensions and allowed formats before exporting final assets.
