# Local loopback OAuth with PKCE; no backend service

The plugin authenticates directly against Google and Microsoft as a public desktop client: it opens the system browser to the consent page, receives the redirect on a loopback listener (`http://127.0.0.1:<port>`), and exchanges the code using PKCE. There is no vo1dee.com auth server — tokens never leave the user's machine. Chosen over a hosted OAuth proxy for privacy (a selling point for a calendar product), zero infrastructure cost, and offline resilience; the accepted costs are polling-only refresh (no webhook push without a server) and passing Google's sensitive-scope verification as a desktop app.
