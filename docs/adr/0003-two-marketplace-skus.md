# Two Marketplace SKUs instead of in-app licensing

Free and Pro ship as two separate Elgato Marketplace listings built from one shared codebase: `com.vo1dee.next-meeting` (free: key action, one account) and `com.vo1dee.next-meeting-pro` (paid $7–9: key + dial actions, multi-account; auto-mute deferred past v1.0). Elgato handles checkout and DRM enforcement at the distribution layer, so the plugin contains no license-key code at all — `isProUser()` is a build-time constant, and the Free/Pro boundary lives in the manifests (the free build simply has no dial action). Chosen over the Lemon Squeezy in-app unlock (ADR-0002, superseded) for zero licensing surface, Marketplace discovery, and Elgato-handled payments, accepting the 70/30 revenue split and the fact that upgraders install a separate plugin and reconnect their accounts (settings are per-UUID). Prerequisite: Maker org with a Stripe-Connect-supported payout country.
